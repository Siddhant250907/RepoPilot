REDESIGN REPOPILOT FROM THE GROUND UP.

Use the attached reference video as the PRIMARY visual and interaction inspiration.

Do NOT copy the reference website, branding, products, text, or exact layouts.

Extract its DESIGN LANGUAGE and translate it into a unique premium identity for RepoPilot.

RepoPilot is an autonomous AI software debugging agent.

It investigates a codebase, creates a plan, autonomously selects tools, executes actions, observes real results, handles failures, replans, and verifies solutions.

The new design must feel like a premium next-generation developer product.

============================================================
3D HIERARCHY
============================================================

Use THREE visual depth layers.

LAYER 1 — ENVIRONMENT

Use 3D for:

- background geometry
- abstract ribbons
- translucent spheres
- orbital structures
- floating shapes
- atmospheric forms
- subtle particles
- large spatial objects

These elements create the world around RepoPilot.

They should remain visually quiet.

------------------------------------------------------------

LAYER 2 — PRODUCT SURFACES

Use glassmorphism for:

- navigation
- task composer
- floating controls
- contextual panels
- modals
- trace containers
- tool cards
- status surfaces

These should generally remain FLAT / 2.5D.

They may have:

- subtle depth
- soft shadows
- glass reflections
- tiny cursor-based tilt
- slight elevation

But they should NOT become fully 3D floating cubes.

------------------------------------------------------------

LAYER 3 — INFORMATION

Keep these primarily 2D:

- typography
- buttons
- labels
- navigation text
- code
- terminal output
- tool results
- metrics
- form controls

Readability is more important than 3D styling.

============================================================
WHERE 3D SHOULD BE MOST PROMINENT
============================================================

Concentrate the strongest 3D effects in only a few locations:

1. HERO

The hero should contain the largest 3D composition.

Use the abstract RepoPilot cognitive engine.

------------------------------------------------------------

2. COGNITIVE LOOP

The:

TASK → PLAN → ACT → OBSERVE → REFLECT → REPLAN → VERIFY

sequence should become a spatial 3D visualization.

This is the primary signature 3D experience.

------------------------------------------------------------

3. FAILURE → RECOVERY

Use 3D motion to show the failed trajectory bending and creating a new path.

This is the second major 3D moment.

------------------------------------------------------------

4. FINAL VERIFICATION

Use a restrained 3D/lighting effect when the system reaches VERIFIED.

The environment can subtly settle into a stable state.

Do NOT create a giant explosion.

The environment should feel massive.

The interface should feel responsive.

============================================================
MOUSE PARALLAX
============================================================

Use cursor position to subtly influence the 3D environment.

Background:
1–2% movement

Midground:
2–4%

Hero 3D:
3–6%

Glass UI:
maximum 1–2%

Never allow the UI to feel unstable.

============================================================
SCROLL DEPTH
============================================================

Scroll should behave like a camera moving through the product.

Do not simply animate individual cards.

Instead:

background moves slowly

3D environment rotates subtly

camera moves forward

glass surfaces enter the scene

typography changes scale

important objects move through Z-depth

The user should feel as though they are travelling through RepoPilot's reasoning system.

============================================================
VISUAL RESTRAINT
============================================================

The design should follow this rule:

80% CLARITY
20% MAGIC

Not:

50% UI
50% EFFECTS

The visual effects should make the product memorable without making the product difficult to use.

The best moments should feel spectacular because everything around them is restrained.

============================================================
SIGNATURE CONTRAST
============================================================

Create contrast between:

LIGHT
→
GLASS
→
BLACK
→
3D
→
COLOR

For example:

A bright off-white section can contain a floating glass panel.

That panel can open into a deep black execution surface.

Inside the black surface:

blue = action

violet = reasoning

coral = failure

lime = verification

This contrast should become one of RepoPilot's strongest visual signatures.

============================================================
FINAL 3D PRINCIPLE
============================================================

3D IS THE ENVIRONMENT.

GLASS IS THE INTERFACE.

TYPOGRAPHY IS THE HIERARCHY.

COLOR IS THE SYSTEM LANGUAGE.

MOTION IS THE STORY.

Do not make every component 3D.

Make the WORLD 3D.

Make the INTERFACE clean.

Make the AGENT'S BEHAVIOR spatial.

Make the USER EXPERIENCE effortless.
